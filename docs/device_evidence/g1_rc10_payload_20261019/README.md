# G1 RC10：链接内容逐字节归因（2026-10-19）

四份 2026-10-16 归档 ELF 的 SHA-256 与先前 [长度复核](../g1_rc10_alignment_20261019/verification.json)一致，本次没有重新调用参考工具。快照头由长度、版本哈希和 features 字符串组成。我们的 features 比参考多 ` shorebird-native-entry-thr-offsets=2312,2320,2328`，正好 50 字节；两侧版本哈希不同。

去掉各自头部后，两侧未链接快照的 93,890 字节序列化载荷逐字节相同，链接后的 94,349 字节载荷也逐字节相同。两侧链接均增加完全相同的 459 字节内容。每侧的附加块均为 173,328 字节，链接前后逐字节不变；两侧附加块之间原本不同，不能误称为跨端相同。因此插入式链接没有留下未归因的载荷内容差。

ELF 符号增长仍分别为 +512 和 +448 字节：459 字节载荷增长加上各自尾部填充变化 +53 与 −11。`verify.py` 读取四份原始 ELF、逐字节比较载荷与每侧附加块，并故意改动一字节载荷确认检查报错。[复核结果](verification.json)包含长度和哈希。RC10 在归档输入的范围内已归因；G1 总体仍未验收。
